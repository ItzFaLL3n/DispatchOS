# Growth System — tiered upgrade offer

Canonical. Source: `_source/growth-system-upgrade-offer.md`. Applies to clients
already on the $39/$49 hosting retainer. This is the Phase 10 offer, not the
initial free build. When a client upgrades into any tier, the standalone
hosting fee stops being billed — it's absorbed into the tier price.

**Framing rule:** this is a service/tooling offer, not a marketing offer.
Nothing here promises leads, calls, recognition, or rankings. Everything is
described as what the system *does* (a real deliverable), never what it *will
get them* (`hard-rules.md` rule 1).

## Eligibility & timing

- **Default:** offer once a retainer client has been on hosting **2+ months**.
- **Exception:** as early as **1 month** if the client shows genuine interest
  first (asks about reviews, mentions missing calls, wants more presence). Let
  his signal drive timing; don't force it.
- **Not for new/free-build clients** — they run the normal sequence first.
- **One offer moment, not three upsells.** He picks a tier or stays on hosting.

## Tiers

### Tier 1 — $197/mo — "Foundation"
- Website hosting + ongoing maintenance (what the old $39/$49 covered — folded in)
- Google Business Profile setup + ongoing upkeep (posts, hours, info current)
- Basic CRM — every customer and job in one dashboard
- Missed-call text-back — a caller who doesn't reach him gets an automatic text
**Solves:** site and listing stop being "set once and forgotten"; a missed call
during a job stops meaning a lost inquiry.

### Tier 2 — $297/mo — "Growth"
Everything in Tier 1, plus:
- AI Review Agent — requests a review after a job is marked complete;
  flags/monitors incoming reviews
- Lead follow-up automation — new inquiries get a text/email sequence
- Simple monthly activity summary (requests sent, texts sent, leads logged —
  activity, not results)
**Solves:** reviews stop depending on him remembering to ask; a lead who
doesn't answer the first follow-up doesn't fall through.

### Tier 3 — $799/mo — "Full System"
Everything in Tier 2, plus:
- AI chat widget on the website — visitors get an instant response
- Full CRM & pipeline view — every call, text, inquiry, review on one record
- Priority turnaround on site changes
**Solves:** the "run it without touching it" version — the full standardized
system in one plan.

## Value framing (reference only — never verbatim client copy)

Use only if he pushes on price. Don't lead with it — leading with it turns a
plain offer into a sales pitch, which has never worked with these guys.

| Component | Standalone cost |
|---|---|
| Custom website build + hosting | $1,500–3,000 build, $50–100/mo hosting |
| GBP management | $150–300/mo |
| Review request / reputation tool | $150–300/mo (Podium, Birdeye class) |
| Missed-call text-back | $50–100/mo |
| Lead follow-up automation | $75–150/mo |
| AI chat widget | $100–200/mo |
| Full CRM w/ pipeline | $100–300/mo |

Stacked separately, Tier 3's components run well past $799/mo.

## Guarantee (service-based, never outcome-based)

- No contract, cancel anytime, any tier.
- 14-day adjustment window after upgrading — anything agreed on that isn't set
  up right gets fixed free and fast.
- No hidden fees — the tier price is the whole price.

## Scarcity (genuine)

Full System setup takes real hands-on time. State an honest monthly cap — e.g.
"only taking on a couple of Full System builds a month right now so each one
gets set up right." Never imply artificial urgency.

## Sample pitch (Phase 10 moment)

> *"hey, wanted to run something by you since things have been rolling for a bit now. i put together a bigger system that folds in everything - hosting, your business listing, review requests, missed-call text-back, all in one dashboard instead of piecing it together. runs $197 to $799 a month depending on how much you want handled, no contract either way. want me to break down what's in each?"*

One message. Don't stack all three tiers' details unless he asks "what's the
difference" — answer from there.
