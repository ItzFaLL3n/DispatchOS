# Relationship Arc — the philosophy under everything

Canonical. Source: `_source/CLAUDE.md` ("Core philosophy"). Every message, pitch,
post, and agent system prompt is filtered through this.

## The one idea

**The free website is not the offer — it's the opening move.** It proves value
and earns trust. It does not close a one-time transaction. The goal is to become
the client's long-term growth partner — the person handling their whole online
presence — not "some guy who built me a site once."

## The arc, every client

```
free website (or free review agent)
  → hosting / maintenance retainer      ($39 self-managed domain / $49 handled)
  → Google Business Profile
  → review agent
  → full growth system                  ($197 / $297 / $799 tiers)
```

## What this means for generated output

No message, post, or pitch is optimised to close **in isolation**. It is
optimised for the relationship it is building toward. By the time a client is a
few steps in they should genuinely need us — not from lock-in, but because we
showed up and delivered at every step.

## Hot-path checklist (mirrored by skills)

- [ ] Does this message serve the long-term partner relationship, or just this
      one conversion? If only the latter — rewrite.
- [ ] Is anything here optimised to close a single step in isolation? Remove it.
- [ ] Would this still be the right message if the client never buys the next
      tier? If not — it is too transactional.
